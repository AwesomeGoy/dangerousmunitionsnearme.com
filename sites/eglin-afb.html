Known energetics or munitions types

The EPA-hosted Florida DEP permit package identifies the facility as a permitted open-detonation operation (EPA ID FL8570024366). A March 2025 open-detonation permit renewal application for Range C-62 has been circulated in the public record; this draft did not independently re-read that entire application for a waste-by-waste inventory. The current listed permit expiration is September 1, 2025.

Current status

The EPA-hosted permit face lists an expiration date of September 1, 2025. EPA's current OB/OD list, last updated March 11, 2025, shows the facility as permitted with that expiration. A public March 2025 renewal application exists for the open-detonation range. EPA notes that conditions of an expired permit continue in force if the permittee has submitted a timely application for a new permit (40 CFR 270.51). This draft did not independently confirm whether a timely renewal was filed or whether a new permit has been issued, unless a source below says so.

Notable incidents

No notable incidents are recorded in this draft. That is not a finding that none occurred.

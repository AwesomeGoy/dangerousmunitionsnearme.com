Privacy

This is a static draft website. It does not have a user account system, and it is not collecting personal information now.

What happens today

  • Pages are ordinary HTML, CSS, and JavaScript files. There is no signup, comment form, or payment form in operation.
  • The “Is there one near me?” ZIP lookup, on the tracker and on the Live near one? page, runs in your browser. The ZIP table is loaded locally. No search, ZIP code, or browser location is sent to this site’s server by that tool.
  • The “ZIP alerts” box is a placeholder. It is disabled, has no mailing-service connection, and does not collect, send, or store an email address or ZIP code.

The site is hosted as static files. The host and your internet provider may keep ordinary technical logs (such as an IP address and the page requested), as most hosts do. This draft does not use those logs to identify a person and does not sell them.

What alerts would collect, if they are turned on

If email alerts are later approved and turned on, the signup would collect only:

  • an email address, and
  • a five-digit U.S. ZIP code.

That information would be used only to send notices about documented changes at tracked sites near the ZIP you provided — for example a newly recorded incident, a permit comment deadline, or a sourced status change. It would not be sold. It would not be used for unrelated marketing. You would be able to unsubscribe from every message. A fuller notice would be posted here before any signup is enabled.
